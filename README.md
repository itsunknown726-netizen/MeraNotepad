MERA NOTEPAD - ANDROID PROJECT

यह Android Studio में APK बनाने के लिए पूरा प्रोजेक्ट है।
फीचर: नया नोट, ऑटो सेव, सर्च, एडिट/डिलीट, Font Size 12-36, Bold और Italic.
थीम: White & Yellow.

APK बनाने का तरीका:
1. Android Studio इंस्टॉल करें।
2. Android Studio में इस MeraNotepad फ़ोल्डर को Open करें।
3. Gradle Sync पूरा होने दें और Android SDK Platform 35 इंस्टॉल करें।
4. Build > Build Bundle(s) / APK(s) > Build APK(s) चुनें।
5. APK app/build/outputs/apk/debug/app-debug.apk में मिलेगा।

नोट्स डिवाइस पर ऐप के WebView local storage में सेव होते हैं। ऐप का डेटा क्लियर या ऐप uninstall करने سے नोट्स मिट सकते हैं।# MeraNotepad
